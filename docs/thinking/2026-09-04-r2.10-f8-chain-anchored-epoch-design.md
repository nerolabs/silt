## 1. The mechanism, in one paragraph

The paid-serial guard's sweep floor and every epoch screen read a `currentEpoch` the CALLER supplies, so the
ledger's clock is a port input any caller or embedder can move, **because** the ledger was built before the
node owned a chain epoch; and with `-epoch-blocks 0` the epoch is permanently 0, the sweep never fires, and
the lane bricks at 65,536 paid deliveries. After O3-T, `chainEpoch()` cannot fall in any shipping posture
(`c.blocks` has two writers, `apply` appends and `adopt` swaps only after a height-first `heavier`), so this
change makes the ledger read its epoch from ONE injected `EpochSource` — the node's `chainEpoch()`, the same
function that prunes the keyset, drives `Bank.Redeem` and verifies relay anchors — removes every epoch
parameter from the ledger's port methods (`RedeemDeliveryCredit[Reason]`, the `deliveryReasoner` twin,
`SpendRelayAnchors`), keeps the max-latch as a PORT contract (a mock or embedder source may fall; a restart
with a rewound chain is the one real case, routed to FP-2 as R-F8-RESTART-REWIND), and refuses in `cmd/silt`
to start `-accept-delivery-receipts` or `-accept-relay-payments` when the effective `EpochBlocks == 0`
(a liveness precondition, NOT a security parameter; core stays permissive for in-process fixtures).

## 2. Rules (verbatim from the cert)
- **R-F8-SOURCE.** The ledger reads its epoch from an `EpochSource` injected once at construction; no
  `ports.CreditLedger` method takes an epoch. Production source = the node's `chainEpoch()`. Finalized-head,
  wall clock and caller-supplied values are inadmissible (finalized-head REFUTED twice: `(0,false)` without
  BFT finality; one epoch behind the keyset at every boundary).
- **R-F8-LATCH.** `epochWatermark = max(epochWatermark, source.Epoch())`, read once at the entry of every
  guarded redeem and anchor spend; sweep floor and every screen use the watermark. A port contract.
- **R-F8-DISABLED.** `cmd/silt` refuses both lane flags when effective `EpochBlocks == 0`, named message
  naming both flags and `-epoch-blocks`; core permissive at epoch 0. Three legacy e2e fixtures gain
  `-epoch-blocks 8` (`e2e/e2e_test.go`, `laneoff_corrupt_store_test.go`, `guardstore_blastradius_test.go`).
- **R-F8-RESTORE** → FP-2 carry-list.

## 3. Refuted / not built
Block-denominated expiry (REFUTED: one predicate on one clock with the keyset window; ticking the keyset clock
is a v5 consensus rule); a per-node default `EpochBlocks` (REFUTED: a per-node value for a swarm-wide input).

## 5. As built (Builder, 2026-09-04)

**Shape.** `ports.EpochSource` (`ports.go`, beside `CreditLedger`); `credit.(*Ledger).SetEpochSource` and
`Epoch()` = `max(watermark, source)` without moving the watermark; one private `advanceEpoch()` called at the
top of the guarded branch of `RedeemDeliveryCreditReason` and at the entry of `SpendRelayAnchors` — it reads
the source ONCE, raises the watermark by max, and runs the C-7 band-advance sweep against the watermark. Every
screen below it (`ReasonBackdated`, `ReasonAnchorFuture`, the cap reserve) is byte-for-byte the previous
control flow with the parameter gone. A nil source reads 0. Daemon: `cmd/silt/ledger_epoch.go` holds
`nodeEpochSource{nd}.Epoch() = nd.DemandEpoch()` (= `chainEpoch()`, a live read) and
`wireLedgerEpochSource(ledger, nd)`, called once right after `nd.EnableChain`. The refusal sits before the
guard-store open, keyed on `effEpoch == 0 && (receipts || relay)`, one `refusing to start` line naming both
flags and `-epoch-blocks`; registered in the S5 `ObservableContract` with the e2e as asserter.

**Call-site migration.** `gofmt -r` over 23 files dropped the last argument (three rewrites, one per method).
Fifteen fixtures used the dropped parameter as their clock and now drive `mockEpochSource` (credit) or
`f8EpochFunc(node.chainEpoch)` (the R2.14 cluster and the composed fixture, i.e. the daemon's wiring
in-process); every assertion is unchanged. `Epoch`/`SetEpochSource` are classified `neutral` in the
Invariant-A map. The remaining fixtures that passed a constant nonzero epoch (`100, 100`; `3, 3`) keep only the
issuing epoch and run at watermark 0: in-window, cap and already-paid behaviour is identical, which is why
they did not break.

**Evidence.** Six gates GREEN; controlled reverts: (a) latch dropped (`watermark = source`) → G-F8-2 (i) both
arms + both G-F8-4 tests RED; (b) `ReasonBackdated` screens read the raw source → G-F8-2 (ii) pays
`(43750, "paid")` / `(50000, "")` and both G-F8-4 RED; (c) the daemon seam wired to a constant → G-F8-6
runtime RED (`ledger.Epoch() = 0` at epoch 1). Suites: the short run over ports / core/credit / core/node /
cmd/silt / adapters/guardstore / adapters/relay / sim, and the e2e file without `-short`, recorded in the PR.

**Not built, by the cert.** The persisted watermark (R-F8-RESTORE, FP-2's clause 4); block-denominated expiry;
a per-node `EpochBlocks` default; a global floor on `EpochBlocks`; auto-wiring the source inside
`node.SetLedger` (declined: it would make ablation (c) undetectable — the seam is the daemon's, and the gate
counts it).

## 6. The three the migration missed (PE ruling `RULING-R2.10-F8-build-178ff3b-2026-09-04.md`)

The first twelve were the ones whose clock moved through an argument the compiler forced me to touch. Three
more moved their clock through a LOCAL variable that still compiled after the parameter was dropped:

- `compaction_fuzz_test.go` computed `epoch := step / fuzzEpochEvery` and, post-migration, bound it only to
  `issuedEpoch`. The watermark stayed 0, the band-advance sweep never ran, and the fuzz's own invariant (d)
  went RED past 32,768 live serials — **but only in the non-`-short` arm**, and CI runs `-short` twice.
- `r214_relay_anchor_test.go`'s `second_spend_refused` lost its epoch-2 arm, and `cap_refuses_never_evicts`
  refused the epoch-1 anchor as future-dated rather than as a cap refusal: both green, neither proving its
  property.

The lesson is not "migrate more carefully": a compiler-driven migration is exactly as thorough as the type
system, and a clock that lives in a local is invisible to it. The gate is the **tripwire**: the fuzz now
asserts that a scenario spanning more than the guard window actually swept, at the tier that runs by default.
A test that claims to exercise a mechanism must fail when it stops exercising it.
