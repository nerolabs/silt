Roadmap

Where silt is now, what comes next, and what is still unsolved. This page changes every time the site is updated or a version is tagged.

Updated 27 November 2026.

Now: getting ready to announce

silt is experimental. There is no binary release; you build it from source. Before we announce it, these must all be true:

  • A live network you can watch. One script runs a whole network on your machine — validators, storage nodes, floor boxes and simulated people publishing and fetching — and the web UI shows it moving. Done; in review.
  • A second, independent red team against the three claims in ADVERSARY.md. The first one's findings are all fixed.
  • A real application on the network. flixz.com serves its film library from silt, through a resolver layer that silt itself never sees.
  • This site rewritten for a source-only, experimental release.

Next: the experimental network

  • A public test network: validators in several regions, storage nodes and floor boxes, with simulated users clearly labelled as simulated.
  • Your bug reports, and your attempts to break it. See SECURITY.md.

Later, and unsolved

  • How many validators. Every validator must receive the others' bond proofs on the live wire, which caps the bonded set at around 125 today. The design target is far larger. This is research, not a patch.
  • Standing that can't be farmed. Standing is earned by proving storage. Two more axes — real demand, and diversity of who holds what — are designed but not built.
  • An external audit, and binary releases once the source-only phase has done its job.
